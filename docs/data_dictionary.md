# Data Dictionary

## Site ID
Unique identifier for each cellular network deployment site.

Example:

SITE-101

## Milestone
Major project activity within the deployment lifecycle.

Values used in this project:

- Site Survey
- Permitting
- Equipment Delivery
- Installation
- Acceptance

## Owner
Person or functional team responsible for the milestone.

Examples:

- Field Engineer
- PM Coordinator
- Logistics
- Installation Crew
- Project Manager

## Planned Start
Scheduled start date for the milestone.

## Planned End
Scheduled completion date for the milestone.

## Dependency
Milestone that should be completed before the current activity begins.

## Status
Current milestone status.

Example values:

- Not Started
- On Track
- Complete

## Percent Complete
Estimated milestone completion percentage.

## Scenario ID
Unique identifier for a simulated delay or resource-conflict scenario.

## Issue
Description of the event affecting the project schedule.

Examples:

- Permit approval delayed
- Installation crew unavailable
- Equipment delivery delayed

## Affected Milestone
Milestone impacted by the simulated issue.

## Delay Days
Estimated number of schedule days affected.

## Resource Conflict
Indicates whether the scenario involves a resource availability conflict.

## Proposed Action
Recommended corrective or recovery action.

## Action ID
Unique identifier used in the project action log.

## Due Date
Expected completion date for an action item.

## Change ID
Unique identifier for a formal schedule change request.

## Schedule Impact
Description of how a proposed change affects the deployment timeline.

## Cost Impact
Estimated financial impact of the change.

## Decision
Current approval status of a change request.
