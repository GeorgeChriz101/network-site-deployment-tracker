# Change Control Process

## Purpose

Change control helps prevent informal schedule changes from creating confusion across the project.

## When to Create a Change Request

A change request may be needed when:

- A major milestone moves
- A dependency changes
- Resources must be reassigned
- A delay affects downstream work
- The planned sequence changes

## Change Request Fields

### Change ID
Unique change identifier.

### Site ID
Site affected by the proposed change.

### Requested Change
Description of what should change.

### Reason
Business or project reason for the request.

### Schedule Impact
Expected impact on project dates.

### Cost Impact
Expected financial impact if known.

### Decision
Current approval status.

## Example Process

Issue identified
↓
Schedule impact reviewed
↓
Alternative approaches considered
↓
Change request created
↓
Stakeholder decision
↓
Schedule updated
↓
Action communicated
