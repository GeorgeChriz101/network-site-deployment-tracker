# Action Log Guide

## Purpose

The action log provides accountability for project follow-up items.

Each action should have:

- Action ID
- Site ID
- Clear action description
- Owner
- Due date
- Status

## Recommended Status Values

- Open
- In Progress
- Complete
- Blocked

## Good Action Example

Confirm revised equipment shipment ETA with logistics vendor.

## Weak Action Example

Check equipment.

Actions should be specific enough that another team member can understand exactly what needs to happen.

## Weekly Review

During a weekly PMO review:

1. Review all open actions.
2. Confirm owners.
3. Check due dates.
4. Escalate overdue actions.
5. Close completed items.
6. Update the schedule when required.
